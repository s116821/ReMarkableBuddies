## Decisions
Keep --model/-m, --base-url, --trigger-corner, --simulate, help/version. Restore --api-key (optional, CLI wins over OPENAI_API_KEY; absent uses env), --log-level (validated off/error/warn/info/debug/trace), --debug-dump (explicit image opt-in). Reject --once, --no-trigger, --screenshot-only and earlier unused input-png/save-screenshot/no-draw. Normal executable always waits for its trigger and runs the loop.

Load optional .env first. Validate normal configuration before device construction. Never derive Debug for credentials or print the argument structure. Help does not expose environment keys. Blank selected credentials fail with a value-free message; an invalid unused env value must not override an explicit CLI value. --debug-dump enables image dumps; otherwise parse READER_BUDDY_DEBUG_DUMP true/false/1/0, default false. This is image output, not a logging enable flag. Retain OPENAI_BASE_URL with CLI precedence.

Logging precedence: explicit --log-level wins over RUST_LOG, otherwise use RUST_LOG when present, otherwise info globally plus debug for reader_buddy and remarkable_reader_buddy. An explicit level applies globally; default dependency debug is avoided. Millisecond timestamps stay. No new dedicated --debug switch. Simulation allows the log-level control but rejects explicit normal workflow/key/dump options rather than ignoring them; its scenario controls provider settings and dumps.

Use a small shared configuration/logging module only if needed to avoid drift between tests/entrypoints. Screenshot example accepts only an output path and constructs Screenshot alone: no credentials or input. reader_once example runs one immediate production iteration with existing env credentials/default model and LL corner, no extra flags; it is explicitly a mutating paid native diagnostic. Keep timeout/watchdog control external, with finite provider timeout. Existing hardware_probe/history helpers remain. Examples are built explicitly, not added to release archives. Documentation describes compile/copy/invoke steps and scope.
