## Repair history and cost

The independent reader originally received a narrow question band. It safely
rejected the known misreading, but also falsely rejected valid G shorthand and
flat-plate handwriting. Clarifying that fragments were valid did not fix G.
A five-capture comparison then showed full-page context read both positive cases
and rejected the three negative cases. The final independent pass therefore gets
an overview and overlapping native detail strips, but never the first proposal.
The final live tests above confirmed the repair. Historical failures remain saved
under `evidence/` and in the [earlier report](rm2-3.28.md).

The approved two-pass Terra configuration costs more than a single-call workflow.
Adding the separate small-sample means gives about **$0.02434 per two-pass question**
versus **$0.01232 for single-call GPT-4o**, roughly twice the cost. This is an
illustrative estimate, not a bill: caching, reasoning, answer length and first-pass
rejection affect actual costs. See the [model comparison](model-comparison.md).

The agent briefly misread “do not spend credits” as an API restriction. The user
clarified that ordinary paid API testing was authorized and only purchasing or
redeeming Codex capacity/reset credits was barred. This did not originate in the
skill or AGENTS. The skill now distinguishes those actions. No reset credit was
used, and no required API-key or hardware-access blocker remains.

## Limits and roadmap

Agreement is a risk-reduction check, not a guarantee of recognition accuracy.
Arbitrary handwriting can still be rejected or misread. Physical human gestures,
reboot behavior, other orientations, older firmware and Paper Pro hardware remain
untested. A native blank successor notes page must still be prepared manually.

Publish the reviewed compatibility PR without automatically merging it. Broader
human-handwriting and device coverage can follow separately. Perplexity changes
and OpenSpec adoption (REM-21) remain deferred.
